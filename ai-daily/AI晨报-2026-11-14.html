开源了，门槛还在
一天三个 Apache 2.0，跑起来的条件没一起给

Cloudflare 把智能体浏览器引擎 Kitesurf 以 Apache 2.0厂商口径 开源；同日 Runway 与 Perplexity 也放出权重。门槛没跟着消失：能下载，不等于跑得起。

11 月 14 日这一天，开放是密集的。Cloudflare 开源了 Apache 2.0厂商口径 许可的 无状态不保存会话状态，每次请求都可以从零开始。对智能体来说，好处是能并发开很多个互不干扰的浏览器；代价是记忆要另外存。浏览器引擎 Kitesurf；Runway 把机器人世界模型 Praxis-1 的权重按 Apache 2.0 放出，允许免费商用；Perplexity 把 Decider v1.3 与 Flash 版放上 Hugging Face。三个项目分属浏览器、机器人、分类决策，彼此不相干，却在同一天用同一个动作回答同一个问题：智能体这层基础设施，开始按「可下载」而不是「可调用」来提供。

但把许可协议读到底，三家的门都只开了一半。Kitesurf 的代码是 Apache 2.0，自己部署却需要 Cloudflare 的 Workers PaidCloudflare 的付费版无服务器运行计划。代码免费，但把它跑在官方网络上要按调用计费，这就是「开源但不自带运行环境」的典型形态。 计划；Praxis-1 权重免费，可要复现 46.2% 的成绩得有对应的机器人测试环境；Decider 是轻量模型，却仍要接进别人的路由与评估链路才有意义。公开的是文件，没公开的是把文件变成服务的那套条件——第 03 版拆浏览器，第 07 版拆模型。

同一天，显卡行业给了一句结构相同的话。面对「英伟达是不是要放弃游戏显卡」的追问，GeForce 品牌负责人 Jacob Freeman 的回答是一个「Nope」；但他只承诺产品线还在，没有承诺价格会下来。报道同时算了一笔账：RTX 5090 从 1,999 美元的首发价走到 9,000 美元，涨幅 370%公开报道。「不放弃」和「买得起」是两件事，这与「开源」和「跑得起」是同一道门。第 05 版逐日记价，第 06 版给一份拿到源码之后的三问清单。

为什么值得把这条线单独拎出来。过去一年，「开放」常常被当成一个开关：开源或闭源。今天这批发布说明它其实是一串条件——许可条款规定你能不能商用、能不能改、改完要不要同样公开。开放权重只说明文件能下载，商用边界要看这一份。、运行环境、硬件门槛、数据依赖，任何一项没给，能力就仍然托管在别人手里。第 08 版写政策开始给智能体定「准入」，第 10 版写资本往这一层砸钱，两边其实都在争同一件事：谁决定准入。

本期不做「该不该用」的推荐，也不预测哪家会赢。只把今天能下载的东西、以及下载之后还缺什么，一条条列清楚。下一期再用同样的口径复查一次，才知道门是在开还是在关。

这一期不评哪家更慷慨。只记一个变化：门槛从「能不能拿到」搬到了「拿到之后能不能用」。

把源码放出来，是一件有明确边界的事：一行许可声明、一个仓库地址、一次发布公告。把运行条件放出来，则没有这么整齐的动作——它散在定价页、部署文档、模型卡的硬件要求里，不会出现在公告标题上。于是读者看到的永远是前半句，要自己翻三四页才能补齐后半句。

今天这批发布把这个落差摆得很清楚。浏览器引擎开源了，但它的天然宿主是付费的无服务器平台；权重放出来了，但模型卡写明首次下载上百 GB、常驻显存上百 GiB；小模型免费了，可它只有在路由、评估与重试链路里才产生价值。这三样都不是缺点，而是「开放」这个词的真实体积。

本报的态度是：不必因此怀疑开放的诚意，但也不该把开放当成终点。一份对读者有用的清单，应该同时写「给了什么」和「还缺什么」——第 06 版那份三问清单就是按这个原则写的，它不打分、不排名，只把条件列齐。

另一处值得留意的是显卡。同一天官方说产品线不会消失，却没有说价格会回来。「继续存在」与「可以被使用」之间的那段距离，和开源与可运行之间的距离，是同一种距离。把这两件事放在同一期读，比分别看两条行业新闻更有用。

给机器造的浏览器 · Kitesurf 与它的邻居 来源 · 官方第 03 版 / 共 16 版

Cloudflare 把 Workers 上的浏览器引擎 Kitesurf 以 Apache 2.0 开源：读页面、跑脚本、截图都在无服务器环境里完成，因为说 Chrome 的 CDPChrome DevTools Protocol，浏览器对外暴露的调试与控制协议。Puppeteer、Playwright 这类工具都靠它驱动浏览器。，Puppeteer 等现成工具可以直接接厂商口径。

同一天出现的三种「给智能体的浏览器」
项目形态关键限制
Kitesurf（Cloudflare）服务端无状态引擎，Rust 组件 + Firefox 样式引擎自部署需要 Workers Paid 计划厂商口径

三条路线争的不是渲染速度，是「谁拥有这个窗口」。服务端方案把浏览器拆成一次请求，好处是能并发开很多个、互不污染；代价是登录态、Cookie 与会话记忆都得另找地方存。桌面方案反过来：agweb 让智能体在后台开标签页，人不被打断，README 给的对比是五个空闲页面约 590 MB，而 Playwright 驱动的 Chrome 约 1.6 GB公开报道。这份数字来自项目自述，本报未复现本报未复现。

「不抢焦点」听着像体验细节，其实是准入设计。智能体要替人操作浏览器，最麻烦的从来不是点按钮，而是登录：密码、二次验证、企业单点登录，任何一步把人踢开，自动化就断在那里。agweb 的做法是把凭据留在密码管理器里、由人填给窗口，智能体只看它该看的部分公开报道。换句话说，门不是拆掉，是加了一道只让特定东西通过的缝。

把第 01 版那句话落到这一版：Kitesurf 的代码可以下载，但它最顺的运行环境仍是一家公司的付费网络；MCP 工具完全免费，却要你自己养一个完整的 Chrome 进程。开源的边界，在这里被画成了「计算谁出」。第 12 版接着看工具链怎么把这笔成本摊开。

世界模型与记忆 · 免费权重、昂贵条件 来源 · 第三方信息网第 04 版 / 共 16 版

Runway 把 Praxis-1 按 Apache 2.0 放出，称可免费商用；斯坦福团队的 Memorilla 把一整份文档集压成极短的记忆表示。两件事都在降低「让模型动手」的成本，但降低的是不同那一半。

先看能拿到的部分。Praxis-1 同时预测机器人下一帧会看到什么、下一步该做什么，在 Nvidia 的 RoboLab-120 世界动作模型测试上厂商自述 46.2%，高于它自己列出的对比模型厂商口径。更值得注意的是训练数据：报道称普通网络视频与专门的机器人采集视频效果相当，这把数据采集这一项从成本表里划掉了一大块公开报道。但它还不能自己规划复杂动作序列，官方也没把这一点藏起来。

再看被压掉的部分。Memorilla 把文档集合压进 16 个记忆 token，喂给冻结的 Qwen3-8B，在 FactKG 上报告 84.33%，所用文档 token 比全上下文提示少 108 倍预印本。这是研究论文口径，未经同行评审，本报未复现本报未复现。它的意义不在分数，而在把「记忆」明码标价：上下文不再是越长越好，而是可以压缩、可以计量的一种资源。

两个项目放在一起，才能看清门槛搬去了哪里。Praxis-1 免了数据费，却把评测环境留在机器人硬件上；Memorilla 省了上下文，却要求你先有一套能生成与校验记忆的训练流程。权重免费，验证成本没有免费。这正是第 06 版三问清单里第二问要处理的东西。

Vercel Labs 同日放出的 UI SDK 是第三个例子：Apache-2.0 测试版，50 多种 UI 行为，覆盖 React、Vue、Svelte、Solid 与 Web Components，让编码智能体把界面拼成可访问组件厂商口径。它开放的是「零件」，不开放的是「审美与取舍」——拼出来的页面合不合用，仍然要人判断。

本版是本报自设方法，不打分、不排名。它只回答一件事：看到「开源」两个字之后，还该问哪三句。

三问清单 · 本报自设，非第三方评级
问什么要找的答案在哪答不出来意味着什么
一、许可允许我做什么许可证原文、商用条款、专利与商标例外能下载不等于能上线，权重与代码不是一回事
二、跑起来还缺什么模型卡的显存与磁盘要求、部署文档、依赖版本公告里的分数是在别家的机器上得到的
三、坏了能不能带走导出格式、状态存放位置、有没有私有服务依赖迁移成本会变成下一轮议价筹码

第一问专治「开放权重」与「开源」混用。权重能下载，只说明文件在你硬盘上；能不能商用、改完要不要公开、能不能转售，全写在许可条款里。今天这批项目多数给了明确协议，这是好事，但读者仍要自己看一眼那几行字。

第二问专治「分数幻觉」。一份模型卡若公布了成绩却没公布硬件，读者就只能猜。把显存、磁盘、依赖服务三项列齐，才知道那个成绩与自己手上的机器有没有关系。这一问不要求厂商自曝全部细节，只要求读者别把缺项当成零。

第三问最容易被跳过。无状态引擎把会话记忆留在外部，服务端浏览器把登录态留在别处，托管工具把审计日志留在平台内；平时不觉得，一旦要换供应商，这些「留在别处」的东西全都是成本。门槛常常不在入口，而在出口。

三问都不需要额外工具，也不产出评分。它们的作用是把一句形容词拆成三条可核对的陈述——这和第 05 版坚持「报价要带日期与口径」是同一种笨办法。

今天放出来的四份权重 来源 · 官方第 07 版 / 共 16 版

模型侧这一天的开放同样密集：专做判断的小模型、推理引擎、标记语言与多模态智能体模型，各自补的是智能体流水线里不同的一格。

Perplexity 的 Decider v1.3 与 Flash v1.3 走的是「分工」路线。两个模型专做二分类与多分类，返回概率供上层做路由、排序与评估，采用双向注意力，Flash 版由 v1.3 蒸馏用大模型产出的数据去训练小模型，让小模型在特定任务上学到接近的判断力，代价是能力范围被收窄。而来；模型以 Apache 协议 在 Hugging Face 放出，同时上 OpenRouter 与 Decisions API厂商口径。它不打算替你思考，只替你拍板——把最便宜的判断从最贵的模型里拆出来。

Baseten 的 DeepSeek Ultrafast 是另一端的活。它服务 DeepSeek-V4.1-Flash，在四张 GB300 上厂商自测约 1,740 token/s，并让会话能在不同服务器之间接续、每台直接从别处拉记忆，因而不需要专门的路由层厂商口径。项目说明还提到，底层代码由编码智能体参与调优公开报道。同样是「开放」，这里交出来的是速度，而速度绑定的是特定芯片。

另外两项更小，但方向一致。Hugging Face 介绍的 LLMON 是一种给大模型读的标记语言，已进 IBM Granite 4.1 的 3B 与 8B 模型；国内团队开源的 Nex-N2.6 是 321B 多模态智能体模型，发布方称重复推理下降约 90%公开报道。前者改的是输入格式，后者改的是推理次数，都不是「更大的模型」。

把四份权重摆在一起看，今天开放的其实不是能力，是可替换性。当判断、推理、格式与记忆都能换件，任何一家模型厂商都不再是唯一的入口；但每换一件，都要重新回答第 06 版的第二问：新零件在我这台机器上，跑得动吗。

锐评 本报评论员 · 针对本版

治理 · 从「能不能做」转到「准不准进」 来源 · 第三方信息网第 08 版 / 共 16 版

政策这一侧的关键词今天不是能力，而是准入：智能体互联的系列国标、白宫的追责口径、以及行业自己划的使用边界，都在回答「谁可以接进来」。

国内：智能体互联系列国标发布。据行业日报汇总，系列标准覆盖 19 个领域，被解读为智能体落地「有章可循」；同期上海为科学数据的 AI 应用立规矩公开报道。标准的意义不在鼓励，而在给「能不能接」一个共同说法——不同厂商的智能体要互相调用，先得对身份、权限与日志有一致定义。本报未核到标准全文，此处按媒体汇总口径记录本报未复现。

行业侧的三条边界更具体。美联航将禁止未经授权的第三方 AI 助手代订机票；Anthropic 的「最严封号」开始穿透审查壳公司与代理中转；微软就全球服务中断道歉，称故障非网络攻击所致公开报道。前两条是把智能体挡在业务系统外面，第三条是提醒所有人：上层再自动，也压在基础设施的可用性上。

与头条那条线合起来读。厂商在开放文件，政策在定义谁能接进来，平台在决定谁会被拦住。「开放」从来不是单方面动作，它是三方各自守着一段门的结果。第 13 版看这些规则落到具体产品上是什么样子。

研究 · 给最响的承诺标个刻度 来源 · 第三方信息网第 09 版 / 共 16 版

这一版不追新模型，只记三份给热度过降温的材料：能干多久、成功率多少、以及一个常被提到的时间表。

自主时长的刻度。一份客服行业的图表被分析师反复引用：AI 智能体现在可以连续工作约 16 小时，但成功率只有 50%，分析师直接把这个数称为「客服场景不可接受」公开报道。「能跑 16 小时」和「跑完 16 小时有人敢用」是两条完全不同的曲线，把后者省略，前者就成了宣传语。

基础设施的时间表。一份被转述的研究认为，太空数据中心在 2030 年前不太可能产生实质影响，前提是发射成本要先降约 15 倍公开报道。礼来 CEO 对「十年内终结重大疾病」的回应也类似：人体临床试验是「帐篷里最长的那根杆」公开报道。两条都不是否定技术，而是在给叙事补一个物理约束。

学术侧仍有硬进展。Google DeepMind 的 AlphaGenome 2 被报道为覆盖 98% 的基因「暗物质」、致病变异识别率翻倍；另有团队在 TorchTitan 上用 384 块 GH200 训练 1T 参数 MoE公开报道。前者是评测口径、后者是工程规模，两者都不宜与临床或商业可用性直接画等号。

本报的记法。凡是「多久、多少、多快」的承诺，都补一栏「代价或失败率」；补不出来的，就标「未给出」。这比替读者判断真假更笨，但更不容易过期。

算力本地 · 服务器那一头先换了代 来源 · 官方第 11 版 / 共 16 版

显卡行情之外，本周更硬的读数来自服务器 CPU：AMD Zen 6 的首份独立实测，以及它给本地推理带来的另一条约束。

先把数字摆齐。EPYC「Venice」旗舰 9996 在双路配置下给出 1,024 线程，Tom’s Hardware 实测 SPEC CPU 2026 整数吞吐较上一代 768 线程产品高 93%；AMD 自述对第五代 Turin 为 2.0 倍 SPECint、2.4 倍 SPECfp、2.7 倍内存带宽，架构层平均 IPC 提升 27%，最大加速 5.3 GHz厂商口径。厂商数字与第三方数字要分开看，本报没有复跑。

同一份实测里的另一个对照更有意思：96 核 EPYC 9686F 在同一篇评测中比英伟达自家的 Vera CPU 整数快 17%、浮点快 40%公开报道。这不是显卡对 CPU 的比较，而是「主机这一侧谁更强」的比较——本地推理的瓶颈常常不在加速卡，而在喂数据的那头。

为什么放在「开源了，门槛还在」这一期。今天放出的权重能下载，但能跑起来的机器规格正在往上走：四张 GB300 的推理引擎、上百 GiB 常驻显存的图像模型、384 块加速卡的训练作业公开报道。硬件门槛不是背景，它是开放条件的一部分。

对普通读者更实际的一句是：服务器 Silicon 的换代通常先于桌面，Zen 6 的核心复合体改动与 3D V-Cache 变体被视作下一代桌面 X3D 的预览公开报道。这条属于路线推断，不是发布承诺，本报按推断标注，不与已实测数字混列。

名词速查 · 本期出现的 14 个词正文里带虚线的词点一下就地解释；这张表留作索引
无状态
不保存会话状态，每次请求都能从零开始。便于并发，代价是记忆要另外存。
CDP（调试协议）
Chrome DevTools Protocol，浏览器对外暴露的调试与控制协议，自动化工具靠它驱动浏览器。
Workers Paid
Cloudflare 的付费版无服务器运行计划。代码免费，跑在官方网络上要按调用计费。
Apache 2.0
一种宽松开源许可，允许商用与修改，要求保留版权与许可声明；它不等于「托管免费」。
开放权重
参数文件可以下载到本地跑。能否商用、能否转售，要看随附的许可原文。
许可条款
规定能做什么、不能做什么的那份法律文本，是「可下载」与「可使用」之间的分界。
蒸馏
用大模型的输出训练小模型，让它在特定任务上学到接近的判断力，能力范围随之收窄。
世界模型
预测环境下一状态并给出动作的模型，常用于机器人控制，评测要依赖具体硬件。
上下文压缩
把长文档压成更短的表示再交给模型，用更少的 token 保留任务所需信息。
推理引擎
负责把模型跑起来、批请求、管显存的软件层，速度往往与特定加速卡绑定。
显存
显卡上存模型权重与中间结果的内存。容量决定能否装下，带宽决定跑得多快。
建议零售价（MSRP）
厂商公布的官方指导价，不是成交价。所有「溢价几倍」都以它为分母。
溢价
成交价高出指导价的部分，通常来自缺货、渠道囤货与套利，不来自产品升级。
