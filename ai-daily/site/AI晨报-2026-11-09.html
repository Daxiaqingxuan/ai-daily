11 月 4 日，OpenAI 上线 Images 2.6。开发者拿到的是两个模型而不是一个：Flare 追速度，官方说低质量图最快 6 秒出；Sunburst 追细节与多轮编辑的一致性。两个模型共用一套新控件——GIF 输出、SVG 导出、标记式局部编辑、以及一个叫 complexity 的复杂度旋钮。费率表印出来是这样的：文本输入每百万 5 美元、图像输入 8 美元、图像输出 30 美元厂商口径。和 2.5 一模一样。

然后有人去翻它的计算器。同样的 1024×1024、同样选 low 质量，2.5 用 196 个输出 token生成一张图按输出 token 计费，不是按张。单价乘以用量才是你付的钱，所以「单价没变」和「更贵了」可以同时成立。，2.6 用 823 个公开报道。按 30 美元/百万换算，单张从约 0.006 美元变成约 0.025 美元，4.2 倍。中质量那一档从约 0.013 涨到约 0.043，3.3 倍。高质量及以上没动，还是约 0.053。

这不是一个「涨没涨价」能回答的问题。价目表的单位是 token，账单的单位是图。当模型在低质量档吐出的 token 变成四倍，费率表可以一字不改，而付钱的人多掏四倍。官方说「价格与 2.5 相同」，这句话在 token 这个单位上完全成立；官方没说「单张成本」，因为单张成本不是它定价的单位。

把量级摆出来就知道这条为什么值得上头版。官方说现在每周生成约 40 亿张图，比九月的 30 亿又涨了一截厂商口径。假设有一个团队每天跑 1 万张低质量草稿，按上面的差额算，一个月多出约 5,600 美元本报自设——这还只是「草稿」，成本本来该最便宜的那一档。越是靠廉价草稿撑迭代速度的团队，越会被这一刀切中。

同一份发布里还有两处需要留意。SVG 导出要计两次费：先出一张参考图，再由一个写作模型把参考图写成矢量文件，两步都算钱，官方没有给固定的单张 SVG 价格公开报道。GIF 只支持生成端点，2 到 64 帧、每帧 20 到 2000 毫秒；编辑端点不能返回 GIF。这些限制都写在文档里，只是不在标题里。

本报的判断是：这一轮发布的信息重心，已经从「能力多强」移到「计费怎么算、兼容会不会坏」。同一天另外三条也是这个形状——Google 的 ADK 把四十多个组件转正，同时收紧了一条能触发 shell 的调用；Claude Code 修好了一个「动作被拒也返回成功」的退出码；四家厂商签的那行 robots.txt 只管未来的抓取，不管已经抓走的内容。四条新闻，四个藏在附带条款里的重点。能力曲线这一周是平的，条款曲线是陡的。

这一周的四条发布，都把最重要的一句放在了标题之外。它们没有说假话，只是每一条都省略了同一个东西：让那句话成立所必需的前提。省略有三种，认出来就不容易被绕。

第一种：省略单位。「价格与上一代相同」——这句话在「每百万输出 token 30 美元」这个单位上完全为真。可用户买的不是 token，是图。同一个模型在低质量档吐出的 token 变成四倍，费率表就可以一个字不改，账单多出四倍。单位是发布说明里最容易被换掉的东西：每 token 换成每张，每张换成每千次调用，每千次调用换成每个「成功任务」。单位一换，任何涨价都能写成降价，而且每一句都不算撒谎。

第二种：省略基线。「快 50%」「工作流快 23%」——比什么快？比上一版、比竞品、比自家上一次内部测试？这一周的框架发行说明里有一句「30 节点、200 轮的工作流快 23%、峰值内存低 9%」，读起来很具体，但没写对比的是哪个版本、跑在什么硬件上、绝对耗时是多少、重复了几次。一个没有基线的百分比，是一个无法被推翻也无法被复现的句子。它的价值不是让你判断，是让你转发。

第三种：省略时间。四家厂商同时承诺遵守一行 robots.txt，用来告诉 AI 开发者「这个站的内容不许拿去训练」。听起来是一次行业让步，读细一点会发现：Anthropic 说已经开始，OpenAI 说未来几个月，微软写的是 2027 年 2 月 1 日，Google 的目标是 2027 年。四家签的是同一句话，生效的是四个不同的年份。更关键的是范围——这行标记管的是今后怎么用，不管已经被抓走、已经进过训练集的那部分。承诺是真的，只是它从签字那天起才生效。

为什么这不等于撒谎。发布说明是营销文件，不是技术文档；它的读者是决定要不要试一下的人，不是要审计它的人。挑对自己有利的单位、省略不方便的基线、把生效日期写在附注里，这些都是这套文体的默认写法，不是某一家公司的道德问题。真正的风险在于：读者把它当技术文档读。当作技术文档读，就会以为「价格不变」等于「成本不变」，「快 23%」等于「你会快 23%」，「承诺遵守」等于「明天就生效」。

所以本期给一个可执行的习惯：每读一份发布说明，去找那三个空位。它用的是哪个单位？它的基线是什么？它的生效时间与范围是什么？三个问题都不难答，答案通常就在同一页的下半部分——只是不在标题里。把这三个问题问习惯，你就不需要相信任何一家的措辞，也能算出自己会不会中招。

本报自己的规矩也是这样长出来的：正文里每个外部数字都带一个标记，说明是谁说的、本报核过没有；每版的来源单独标注；事实卡里的数值必须能在正文原处找到。不是因为我们比厂商更诚实，是因为我们把「这句话凭什么」写在了句子旁边，读者可以不同意，但知道该去核哪里。

最危险的不是省略，是省略得太自然，以至于读者替它补全。看到「快 50%」，我们自动补上「比上一代」；看到「价格不变」，自动补上「我不会多花钱」。发布说明省掉的那半句，最后是读者用自己的钱补上的。

能力底座 · 同一天，把便宜的和危险的分开卖 来源 · 官方第 03 版 / 共 16 版

这一周模型侧最值得看的不是某个分数，是定价表的结构：同一个生成代里，最便宜的档降到上一代的一半，最危险的那档按二十倍的价格单独卖。能力分层第一次被写成了价格分层。

先说便宜的那一头。GPT-6.1 Terra 在 ChatGPT 的工作场景、Codex 与 API 同时上线，每百万 token 输入 1 美元、输出 5 美元厂商口径，正好是 GPT-5.6 Terra 的一半。官方给它的定位是「快而便宜的计算机操作computer use。模型看屏幕、点按钮、敲命令行来完成任务。它让「自动办事」成立，也让权限边界变得重要。」，并称其在约 1/10 的 token 价格上追平 GPT-6 Astra厂商口径。

这句话的算法值得拆开。1 美元输入、5 美元输出，是相对 GPT-5.6 Terra 说的；「1/10 token 价」是相对 Astra 说的。两个基准不同的比值被写在同一句里，读者很容易读成「便宜了十倍还一样强」。本报没有复现任何一项本报未复现，只能说：如果这个比值成立，它意味着 Astra 的实际使用成本在每百万 10 美元输入、50 美元输出这个量级；如果不是，那就只是又一次没有基线的比较。但它至少给了一个可以被算的承诺——价格写在明面上，谁都能验。

再说危险的那一头。同一代里的网络安全变体有两个数字：ExploitGym 得分 48.5%，上一代同系列是 32.1%厂商口径；定价 每百万输入 20 美元、输出 100 美元，比通用档贵二十倍，且只对 Daybreak Red 客户开放，走 API 与 Codex 两条通道。第三方清单把它标为网络安全类别里的最高风险等级公开报道。

把这两头并排放，结构就出来了：通用能力在降价，专用危险能力在涨价并收窄入口。这不是矛盾，是同一套定价逻辑的两个方向——越是「谁都能用、错了也不太要紧」的能力，越要便宜到没人犹豫；越是「用对了是审计、用错了是武器」的能力，越要用价格和准入把它围起来。二十倍不是成本，是门槛。

另一条线来自开源侧。一个 753B 的科学模型用 MIT 许可放出权重，从 GLM-5.3 后训练而来，面向化学、材料与生命科学，支持 1M 上下文，提供 BF16 与两种 4 位量化格式厂商口径。科学模型愿意用 MIT 而不是「研究用途」许可，是一个信号：它判断自己的风险不在滥用，在没人用。这个判断对不对，要看接下来有没有非厂商团队的复现结果。

本报的判断是：「能力分层」这件事，今年第一次从评测榜走到了价目表上。过去我们说某个模型「更强」，指的是分数；现在我们能说某个模型「更贵」，指的是同一件事。这对读者其实是好事——分数可以吵，价格不能吵。一张写在明面上的价目表，比十个没有基线的百分比更接近事实。

把最危险的能力定价定到二十倍，是一个诚实的设计：它承认了这个东西不该被随手调用。真正该警惕的是另一种做法——把危险能力混在通用档里，用同一个价格卖出去，然后在条款里写一句「请勿用于攻击性用途」。用价格设门槛，比用条款设门槛有效得多。

这一周开发者工具的更新密度很高：一个编码代理、一个智能体框架、一个命令行工具，各发一版。三份更新日志的标题都很轻，但每一份里都有一行会让现有代码改变行为的东西。

Claude Code：把「假成功」修掉了。2.1.319 最显眼的两项是MCPModel Context Protocol。让模型调用外部工具与数据源的接口标准。服务器可能把一个调用标记为「任务」，跑很久才返回。 任务转后台——服务器把一次工具调用当任务跑时，客户端立刻把它放到后台，完成后再把结果告诉模型；以及一个新权限项 permissions.denyInsteadOfPrompting，把「需要人工批准」的调用直接拒掉而不是挂在提示上，让无人值守的回合继续往下走。厂商口径

真正值钱的是第三条，几乎没人转发：此前在自动模式下，如果安全校验不可用，claude -p 的动作即使被拒绝，进程也退出 0厂商口径。脚本只看退出码，就会把「什么都没干」当成「干完了」。这一版把这种情况改成退出 1。这是一个把静默失败变成显式失败的修复——它不增加任何能力，但它让「今晚的批处理到底跑没跑」这个问题第一次有正确答案。同一版还修了一个工作树创建时触发的沙箱逃逸与一处 Bash 权限检查绕过。

ADK：转正的代价是一次收紧。2.14.0 把 42 个组件从实验状态转正（26 个模块 + 16 项工具与集成能力），A2AAgent2Agent。让一个智能体把任务交给另一个智能体并取回结果的协议；和 MCP 的分工是「连工具」与「连同行」。 集成、执行环境与评估栈一起进稳定状态，新增 adk generate_agent_card 生成 agent card智能体的公开名片：叫什么、能接哪些任务、怎么找到它。别的智能体靠它决定要不要把活派过来。。厂商口径

同一次转正里有一条破坏性变更breaking change。升级后旧代码不再按原样工作。通常不是 bug，是有意改了接口或语义。：RunSkillScriptTool 过去接受一个自由形式的 shell 命令，现在只接受校验过的脚本路径与参数（只支持 .py、.sh、.bash），仍然传 command 的调用会返回 INVALID_ARGUMENTS。官方说明的理由是堵住一条「提示注入可以触发任意 shell 命令」的路径。此外 Enum 类型的工具参数现在以枚举成员而不是字符串传入，会话创建接口也收紧了多余参数。「stable」在这里的意思是「以后不再随便改」，不是「升级不会有感觉」。

Codex CLI：把「跑到哪了」做成一个列表。0.167.0 引入 codex agents --no-daemon，打开一个代理任务列表，列出正在跑的和已经结束的，未读结果单独标记；终端会话选择器里可以切换后端而不丢正在写的草稿；本地图片附件在输入时能预览。这些都不是能力，是把「同时开五个代理」从混乱变成可管理。厂商口径

本报的判断是：这一周三个工具动的是同一根神经——无人值守时的可观测性。MCP 任务后台化是为了不让慢调用堵住回合，拒绝而不等待是为了不让提示卡住整晚，退出码修正、代理列表、会话不丢草稿，全都在回答同一个问题：没人在旁边看的时候，它到底做完了没有。能力提升会带来新的用法，可观测性提升才决定这套用法能不能被信任。

四家大厂同一周承诺遵守 robots.txt网站根目录下的抓取约定文件。它是君子协定，不是技术屏障：遵守与否取决于对方愿不愿意读。 里的一行新标记，用来声明「本站内容不许用于训练」。这是真进展，但它有四个限定，四个都不在标题里。

先说这一行是什么。它叫 __usage_ai-training，写在 robots.txt 某个 User-Agent 组的策略行里。过去一个站点想拒绝所有家，得给每家爬虫各写一条规则，有时同一家公司还要写好几条——因为一家公司常常同时跑采集、搜索、训练三种爬虫。这行标记想做的是把那些规则收成一条：所有参与方用同一种读法理解它。草案由 Anthropic 的 Kevin Kelley 同日提交到 IETF，属于个人提交的 Internet-Draft预印本。

限定一：它声明的是「怎么用」，不是「能不能抓」。这行标记不阻止任何机器人取走页面；它只是表达「取走之后别拿去训练」。区别很大：前者有技术手段可以强制（封 IP、验证 UA、上反爬），后者完全靠对方自觉。把它读成一道墙，会高估它；把它读成一句公开声明，才是它的本分。

限定二：它不追溯。承诺生效那天起才管用，对已经抓走、已经进过训练集的内容不起作用。这一点在报道里通常被写成一句「对已收集内容无效」，轻描淡写，但它其实是整件事里对站点主最要紧的一条——被用得最多的内容，恰恰是最早被拿走的那批。

限定三：四家签的是同一句，生效的是四个时间。Anthropic 说已经开始实施；OpenAI 说会在未来几个月内支持，没有给日期；微软写的是 2027 年 2 月 1 日起在抓取时遵守；Google 的目标是 2027 年。另有报道称 Meta 表态支持但尚未承诺，同时把它修订后的商业条款推迟到 11 月 20 日公开报道。也就是说，从今天到明年二月，这个标记对最大的一批抓取方仍然只是建议。

限定四：草案本身没有正式地位。IETF 自己的追踪系统把它标为个人草案，未获该组织背书、无正式效力，2027 年 5 月 3 日到期，除非被修订公开报道。这意味着现在把「业界标准」四个字用在这行标记上，是提前了至少一年。它是四家公司的自愿承诺，加上一份会过期的草案。

然后是这一版最值得记的一条：只停训练，可能连带丢掉引用。Google 的说法是，若站点只用共享标记退出、没有单独指定它自家的 Google-Extended，它计划「视为出版方已经禁止了 Google-Extended」。问题在于 Google-Extended 同时管着 Gemini 回答里的内容引用。结果是：一个只想拒绝训练、并不拒绝被搜索到的站点，可能连在 Gemini 答案里被引用的机会一起失去公开报道。对靠流量活的内容站，这个代价可能比「被训练」更直接。

微软走的是反方向：训练侧接受共享标记，另外加一个页面级的 AI 引用偏好，其中一项可以保留自家产品的引用、同时排除对外售卖的引用服务。同一行标记，两家给出了两种取舍。这说明共识只到「读同一个词」为止，往下怎么执行，各家还在按自己的商业结构安排。

本报的判断是：这是一次真实的让步，也是一次被高估的让步。真实在于，过去站点主要靠逐条写给每家公司，现在至少有一个共同词汇；被高估在于，它不阻止抓取、不追溯、不立即生效、也没有正式标准撑腰。对内容方，最务实的做法不是等 2027 年，而是在自己的页面上同时做三件事：写清偏好、留好抓取日志、给「不训练但可引用」留一条单独的开关。最后这一条今天还没有任何一家提供，而这正是缺口所在。

思路拆解 · 五问一份发布说明 来源 · AI 生成第 06 版 / 共 16 版

这一期的四件事，用五个问题就能全部问穿。这五个问题不需要任何专业知识，只需要在读之前先问，而不是读完之后再想。本版把它写成可以直接照做的清单。

第一问：单位是什么？凡是数字，先找它的分母。「每百万 token 30 美元」和「每张图 0.025 美元」是两个不同的东西；「转正 42 个组件」和「减少了 42 处工作量」也是。发布说明里被悄悄换掉的往往不是数值，是单位——数值改小了要被质疑，单位换掉没人会发现。看到百分比，问它是谁的百分比；看到倍数，问它是谁除以谁。

第二问：基线是什么？「快 50%」必须有一个「比什么」。比上一代、比竞品、比自家三个月前的内部构建，是三种完全不同的说法。判断方法很土：在文档里找有没有版本号、硬件、绝对耗时、重复次数。四样里缺两样，这个百分比就只能当形容词用，不能当决策依据。一个诚实的性能声明通常长这样：某个版本、某台机器、某个工作负载、跑了几次、耗时从多少到多少。写不出这个句式的，多半是自己也没测全。

第三问：什么时候生效，管不管已经发生的事？这一问在政策类、治理类声明里最关键。承诺生效的日期、生效的范围、对存量数据是否追溯，是三件独立的事。把「将来不这样」读成「现在没问题」，是最常见的一种误读。同样，软件类声明里的「已支持」也要问一句：是全量开放，还是分批放量、需要申请、或者只对某个区域开放。

第四问：旧的东西会变吗？升级类文档里最该先看的是「破坏性变更」那一节，而不是「新增功能」。新增功能你不用可以不理，破坏性变更你不理它会来找你。具体要找四样：退出码、返回值类型、参数格式、默认值。本期就有三个现成例子——脚本执行从自由命令改成校验路径、枚举参数从字符串变成枚举成员、动作被拒时的退出码从 0 变成 1。三条都不在新功能列表里。

第五问：谁验过？官方自测、第三方复算、独立复现，是三档完全不同的证据。这一期里，唯一被第三方真正算过一遍的是图片的 token 用量——因为计算公式是公开的，谁都能拿计算器反算。能被外人独立算出来的数字，可信度天然高于只能被内部跑出来的分数。反过来，一个只有厂商自测、又不公布测试集的数字，最合理的处理方式不是不信，是「先记下，等第二个来源」。

五问问完，给一个三档反应。第一档「今天就能用」：五问都清楚、基线明确、兼容影响可接受——直接换，别等。第二档「小范围试」：基线模糊但方向可信，值得在自己的数据上跑一遍再决策。第三档「只记不动」：只有厂商自述、又没有可复现的测试条件，记进观察清单，等第二个来源。大部分发布都落在第二档，而不是很多人默认的第一档或第三档。

最后一句关于这套方法本身的边界。它能筛掉措辞上的水分，筛不掉方向上的错误——一个基线写得很规范的声明，也可能是错的。所以它只能当第一道闸，后面必须跟一次真实的小规模验证。五问的作用不是让你不做验证，是让你把验证花在值得的地方。

开源清单 · 四份权重，四种许可 来源 · 官方第 07 版 / 共 16 版

这一周放出来的四份权重，规模从 4B 到 753B，许可从 Apache 2.0 到 MIT 再到一个自造的名字。许可比参数更能说明「放出来想让你干什么」。

Ripple-65B Preview：编码方向，Apache 2.0，权重直接下。来自 Ricursive Intelligence，团队出自 Google，主打开放编码基准上的领先与「低成本托管入口」公开报道。Apache 2.0 意味着商用、改、再分发都不需要额外授权——这是四份里对使用者最宽松的一份。它同时提供托管入口，说明这家公司赌的不是卖权重，是卖「比你自己搭更省事」。

753B 科学模型：MIT 许可，但权重门控。从 GLM-5.3 后训练，面向化学、材料与生命科学，支持 1M 上下文，提供 BF16 与 NVFP4、MXFP4 两种 4 位量化版本厂商口径。许可是 MIT——和 Apache 2.0 一样宽松；但权重是门控权重下载前要登记或申请。许可再宽松，拿不到文件也白搭；门控通常用来把「谁在用」记下来。，需要申请才给。这种情况下，「MIT 许可」的实际含义是：拿到之后你可以随便用，但能不能拿到不由许可决定。

Mage-VL-Cowork 4B：微软放的操作模型，Apache 2.0。4B 参数，把图形界面的点击与命令行操作放进同一个策略里——遇到按钮就点，遇到需要跑命令的场景就切到 shell，不需要外挂两个模型厂商口径。官方自报在 OSWorld-Verified 上 66.0%。这个数字是实验室口径，本报未复现，也没有在同一测试集上的第三方对比。4B 能跑在消费级显卡上，这是它真正的卖点——把「让模型自己操作电脑」从云端拉回本地。

74B-A9B 两比特版：约 24 GB，本地代理方向。由 Super VL 派生的本地MoE混合专家。把模型拆成很多「专家」，每个 token 只叫醒其中几个；能力按总量算，成本按叫醒的数量算。 模型，权重压到 2 bit 后约 24 GB，许可为 OpenMDW-1.1厂商口径。24 GB 这个数字值得停一下：它刚好落在单张消费级显卡的容量线上，意味着「本地跑一个接近中型的代理模型」第一次不需要多卡。代价是 2 bit 量化的能力损失，公开材料没有给出与全精度版本的对照。

四份放法，四种算盘。Apache 2.0 加托管入口，是「权重给你，省事卖我」；MIT 加门控，是「法律上不设限，名单上要留名」；4B 全开放，是「先占住本地操作这个位置」；2 bit 压到单卡容量，是「把门槛从机房降到桌面」。开源这个词已经装不下这些差别了。真正该问的不是「开不开源」，是「哪一段给了你、哪一段留在对方手里」。

本报的判断是：这一轮开源的竞争点，已经从「参数量」移到「能不能在你要的地方跑起来」。753B 再大，跑不动就只能调 API；4B 再小，能塞进笔记本就有完全不同的用法。对做产品的人，许可与体积比分数重要——分数决定上限，许可和体积决定你能不能开始。

「MIT 许可」这四个字现在有两种用法：一种是真的把东西交出去，一种是让法务看起来没问题、再在下载页加一道申请。判断方法只有一个——去点一下下载按钮，看它给不给你文件。给，就是开源；不给，就是「开放得很有诚意」。

安全治理 · 这一周的三次收紧 来源 · 官方第 08 版 / 共 16 版

这一周没有出现「新的重大漏洞」，出现的三件事都是同一类：把过去为了方便而留的口子，往回拧了一格。这类改动通常不开发布会，但它决定了智能体能不能被放在没人看着的地方。

第一次收紧：脚本执行不再接受自由命令。框架 2.14.0 把技能脚本的执行方式改了——过去 RunSkillScriptTool 接受一个自由形式的 shell 命令，现在只接受校验过的脚本路径与参数。官方给出的理由很直接：旧做法留了一条「提示注入把指令藏在文档、网页或工具返回值里，让模型当成自己的任务执行。它不需要攻破系统，只需要说服模型。可以触发任意 shell 命令」的路径厂商口径。旧写法现在会返回 INVALID_ARGUMENTS，配套的提示词与评测数据也得跟着改。

为什么这一条比它看起来严重。智能体跑在沙箱限制程序能碰什么的环境。它决定「即使模型被骗了，最坏能坏到哪」——这也是沙箱设计比模型对齐更可靠的地方。里，是为了让「模型说错话」不至于变成「机器被接管」。但如果工具层自己提供了一个执行任意命令的入口，沙箱的边界就形同虚设——攻击者不需要让模型变坏，只需要让模型读到一段恰好包含命令的文字。这类问题的修复通常很难看：要把一个灵活接口改成受限接口，所有依赖它的人都会骂。这一版选了改。

第二次收紧：编码代理修掉了两个能越界的地方。2.1.319 一并修的还有一处创建 worktree 时触发的沙箱逃逸，以及一处 Bash 权限检查绕过厂商口径。前者意味着「本该被关起来的代码跑到了关它的地方之外」，后者意味着「本该被拦下的命令被放行了」。两个都出现在日常最常用的路径上——一个在开分支时，一个在跑命令时。这类洞的特点是：不出事的时候完全看不出来；出事的时候，你已经把权限给它了。

第三次收紧：主动请外人来打自己。有报道称 OpenAI 与安全公司 Hacktron 合作，用后者的工具审查自家系统与集成公开报道。这件事的意义不在结果——结果通常不会全公开——在于它把「谁来验」这个问题从内部挪到了外部。上一期本报的主线是「谁验过才算数」，这一条算是那个问题的半个答案：让不在利益链上的人来验，比在发布说明里自证要硬。

还有一个方向相反的观察。同一周那个网络安全专用模型的定价与准入，本身就是一次安全设计：得分更高的那一档被单独拎出来，只对审核过的研究客户开放，价格定到通用档的二十倍。它承认了「这类能力不该被随手调用」，用价格和名单两道门把它围住。这比在条款里写一句「请勿用于攻击」有效得多——条款拦不住想用的人，价格和名单可以。

本报的判断是：智能体的安全，正在从「模型会不会说错」转向「工具链会不会被借用」。前者靠对齐，后者靠接口设计。这一周三件事全落在后者：一个把自由命令改成校验路径，两个把越界的路堵上，一个把外部审查请进来。这些改动都不会让产品变得更好用，只会让它更敢被用。

学术前沿 · 改 0.016% 的参数，把数学从 7.9% 拉到 48.1% 来源 · 第三方信息网第 09 版 / 共 16 版

这一周最值得看的一项结果，不是又一个更高的分数，而是改分数的路径变了：不重训、不蒸馏、不靠提示词，直接去改另一组权重训练出来的参数文件。改权重就是改模型本身，和改提示词、加检索是两回事。里的一小部分。

先说结果。有报道称 MIT 的团队用 GPT-6 Astra 直接编辑了 Qwen 的开放权重，在 MATH-500 上的成绩从 7.9% 提到 48.1%，而被改动的参数只占约 0.016%预印本本报未复现。这个比例意味着，如果原模型有 300 亿参数，被动到的不到 5 万个。

为什么这件事不寻常。提升一个开放模型的能力，过去有三条路：继续预训练（要算力）、监督微调（要数据）、蒸馏（要一个更强的老师）。三条路都在改大量的参数。这次的做法属于第四类，报道里叫「权重空间编程」——让一个模型去读另一组权重、找到与某类能力相关的那一小块、然后直接写回修改。读和写都在权重层面发生，不经过梯度下降。

这条路如果成立，意义不在于「省算力」，在于它把模型当成可以被直接编辑的对象，而不是只能被训练的对象。过去我们说「这个模型不会数学」，只能靠在数据上再训练一遍；如果定位与改写可靠，理论上可以只动那一小块——像改一行配置，而不是重新编译整个程序。蒸馏把大模型的能力搬到小模型上：用大模型的输出当训练目标。搬得好省算力，搬不好会把偏差一起继承。是把老师的答案抄过来，这条路是直接改学生的脑子。

但必须把边界写清楚。其一，7.9% 这个起点低得不正常——一个正常的开放模型在 MATH-500 上不该只有个位数，这说明被编辑的可能是极端受限的配置（小模型、低比特量化，或未经指令微调的基座）。起点越低，能提升的空间越大，这个结果就越不能外推到「已经很强的模型还能再涨 40 个点」。其二，MATH-500 是数学单科，题量五百道，单科上的大幅提升不能推一般能力。其三，本报没有复现，也没有看到同行评审——它目前是一条报道，不是一篇被验证的结论。

第一道线是显存。约 24 GB 的权重文件，加载进显存之后还要留出上下文缓存与运行时开销。按常见实现估算，权重占满 24 GB 时，能留给上下文的余量已经很少；想跑长任务，实际需要的显存要比权重大一截本报自设。所以「24 GB 卡能跑」这句话在技术上成立，在体验上要打个折——它更接近「能启动并完成短任务」，而不是「能挂着跑一整天」。

第二道线是量化。这份权重压到 2 bit，靠的是把每个参数从 16 位压到 2 位。同一周的另一份科学模型提供了 BF16 与两种 4 位格式（NVFP4、MXFP4）厂商口径，也是同一个逻辑：用精度换显存。问题在于，公开材料通常只给压缩率，不给「压完之后掉了多少」的对照——没有同一测试集上的全精度与量化版对比，你就无法判断省下的那 20 GB 是用什么换的。本报的建议是：任何量化版都先在自己的任务上跑一遍，别拿别人的压缩率当自己的性价比。

第三道线是上下文。2.15 万亿参数的模型标称支持百万级上下文，753B 的科学模型也标 1M厂商口径。标称容量和可用容量是两件事：上下文越长，缓存占的显存越多，在本地这个约束比在云端尖锐得多。云端可以把长上下文摊到多卡上，本地只有一张卡。结果就是：本地能跑的任务，往往是「上下文短、步骤多」那一类——反复调用工具、每次只看一小段，而不是「一次读完一百万字再回答」。

把四道线并起来看，本地部署的现实位置就清楚了。能落在桌面上跑的，是「4B 级的专用模型」和「2 bit 压过的中型代理模型」，适合做的是受控任务：整理文件、跑固定脚本、在几个应用之间搬数据。跑不了的，是那些需要长上下文、需要高精度推理、需要和云端最强模型掰手腕的活。这不是妥协，是分工。云端负责「难而少」的调用，本地负责「易而多」的重复——按调用量算账，这个分工通常比全放云端便宜。

本报的判断是：本地推理这一年真正的变化，不是「能跑更大的模型」，是「能跑得起代理」。过去本地只能跑一个问答模型，现在能跑一个会调工具、会看屏幕、会自己重试的东西——它对显存的要求更高，但对「值不值得本地跑」的判断反而更简单：只要这个任务每天重复几百次、且不需要联网，本地就是划算的。

MCP / Model Context Protocol
让模型调用外部工具与数据源的接口标准。服务器可能把一个调用标记为「任务」，跑很久才返回。
A2A / Agent2Agent
让一个智能体把任务交给另一个智能体并取回结果的协议；和 MCP 的分工是「连工具」与「连同行」。
agent card
智能体的公开名片：叫什么、能接哪些任务、怎么找到它。别的智能体靠它决定要不要把活派过来。
ACP / Agent Client Protocol
编辑器与编码代理之间的接口约定。它让同一个代理能接进不同编辑器，像 LSP 让语言工具接进不同 IDE。
破坏性变更 / breaking change
升级后旧代码不再按原样工作。通常不是 bug，是有意改了接口或语义。
robots.txt
网站根目录下的抓取约定文件。它是君子协定，不是技术屏障：遵守与否取决于对方愿不愿意读。
门控权重 / gated weights
下载前要登记或申请。许可再宽松，拿不到文件也白搭；门控通常用来把「谁在用」记下来。
MoE / 混合专家
把模型拆成很多「专家」，每个 token 只叫醒其中几个；能力按总量算，成本按叫醒的数量算。
提示注入 / prompt injection
把指令藏在文档、网页或工具返回值里，让模型当成自己的任务执行。它不需要攻破系统，只需要说服模型。
沙箱 / sandbox
限制程序能碰什么的环境。它决定「即使模型被骗了，最坏能坏到哪」，也是比模型对齐更可靠的边界。
权重 / weights
训练出来的参数文件。改权重就是改模型本身，和改提示词、加检索是两回事。
蒸馏
把大模型的能力搬到小模型上：用大模型的输出当训练目标。搬得好省算力，搬不好会把偏差一起继承。
