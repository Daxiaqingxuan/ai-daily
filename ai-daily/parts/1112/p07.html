开源清单 · 六个项目，四种「省事」 第 07 版 / 共 16 版

11 月 11 日的开源榜单几乎被「围绕智能体的工具」占满。它们不训练模型，只替你把模型外面那圈麻烦事做掉：看懂别人的程序、把它关进笼子、教它怎么教人、以及不用云账号就能测代码。本版按「省的是什么事」归类，不按热度排。

省掉「看不懂」。morluto/rea 让编码智能体在没有源码的情况下逆向一个应用：通过 Hopper 或 Ghidra 看原生二进制，也能看 JavaScript / Electron 应用、.NET 程序集和网站，最后连证据与结论的边界一起给出，分析在本机跑公开报道。storytold/craft-anything 走得更远，用净室方式观察可见行为再让智能体重建，早期 alpha，314 个工具同时可作 CLI 与 MCP 用。这两件东西改变的不是模型能力，是它能被指派去读什么。

省掉「管不住」。Lee-xeo/Claude-Cage 把 Claude Code 与 Claude Desktop 放进隔离虚拟机，网络走代理、时区与语言跟随出口节点，只共享你选中的项目目录，还能在配对手机上继续或批准会话公开报道。和第 05 版的四道闸一样，这是把边界写在环境里，而不是指望模型自觉。

省掉「不会教」。两份技能包值得放在一起看：Jane Street 的 agent_skills 只带一个 socratic-tutor 技能，先做诊断、画 0 到 5 级的技能图、一次只问一个问题、安排间隔复习；GoogleChrome/modern-web-guidance 由 Chrome、Edge、Firefox 与 MDN 团队共同维护，给编码智能体喂现代 Web 平台的策展指南，还能扫代码库里的旧写法公开报道。「技能」这一层正在变成可分发的东西，而它恰好也不改一个权重。

省掉「测不了」。aws/aws-emulator 是 Rust 写的本地 AWS API 模拟器：起一个实例，把 AWS CLI 或 SDK 指过去，无需账号就能对着模拟资源调试；每个版本按服务公布保真度评分，覆盖 200 多款云服务、438 个 API 模型厂商口径。它默认开启用量遥测，这一点在把它接进内网之前值得先看一眼。meta/astryx 则把内部用了八年的设计系统开源：150 多个 React 19 组件、七套主题，安装就是普通 CSS 加带类型的组件，刻意做成智能体和人用起来一样顺公开报道。

把这六件摆在一起看，本期主线就更清楚了。它们不比参数、不刷榜，全部在处理「模型之外」：输入怎么拿到、运行怎么圈住、知识怎么喂、代码怎么测、界面怎么画。一个生态成熟的标志，往往不是又多了个大模型，而是这类不起眼的工具开始成批出现。

锐评 本报评论员 · 针对本版开源清单

最值钱的开源项目常常一点也不炫：它只是把一件你每周都要做、又没人愿意写进发布说明的脏活做掉了。本周这六个，全属于这一类。
