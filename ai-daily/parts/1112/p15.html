前十条是这两天已经发生的，后面是有明确日期或明确可验证条件的观察清单。本报不写「预计」「有望」。公开报道

  • 界面：Google 发布 A2UI 1.0 首个稳定版，智能体描述内容、应用画原生界面，协议以 Apache 2.0 开源。
  • 版本：官方博客写 1.0 为现行版，Gemini Enterprise 注册侧仍支持 0.9.1，Jetpack Compose 渲染器仍为 alpha。
  • 护栏：OpenRouter Agent SDK 加四道闸，在 6 个模型上测试，第三次重复调用被拦下；技术细节未公布。
  • 本地：aws-emulator 覆盖 200 多款云服务、438 个 API 模型，按服务公布保真度，用量遥测默认开。
  • 兼容：LangChain 全系新版最低 Python 3.11，3.10 用户可继续留在 1.4.x。
  • 计价：Bedrock AgentCore 网页搜索 API 每 1000 次查询 7 美元；Gemini Decisions API 每百万输入 token 0.1 美元。
  • 端侧：Tether BotPsy-0.8B 以 Apache 2.0 开放权重，BFCL v4 厂商自述 44.0%，不含训练数据与代码。
  • 治理：纽约 RAISE Act 生效，关键事件 72 小时内报告，重复违规最高罚 300 万美元。
  • 安全：Git 修复六个涉及递归克隆、合并与补丁的漏洞；N-able 建议部分自托管客户先下线。
  • 资本：Anthropic 更新 S-1，估值 1.4 万亿美元、代码 ANT；软银美国数据中心投资减值 70 亿美元。

接下来盯什么（有条件的观察清单）

  • Anthropic 定价：条件是「11 月 19 日前后」。盯最终定价是否落在 70–78 美元区间内，而不是盯传闻里的估值上沿。
  • Copilot 默认开关：条件是「12 月 9 日」。盯英国租户的管理员复核期限过后，默认值有没有从「允许」改成「需选择」。
  • RAISE Act 登记名单：条件是「1 月 1 日前登记」。盯名单是否公开，以及「关键事件」的界定文件有没有先出台——没有界定，72 小时就无从核起。
  • Jetpack Compose 渲染器：条件是「官方称 1.0 支持即将到来」。盯它何时脱离 alpha；这是 A2UI 六条路径里唯一还停在 alpha 的一条。
  • 四道闸的技术细节：条件是「官方公布阈值与误伤恢复方式」。在此之前，第 05 版表格里那四格「未写明」就一直不擦。
  • 趋势榜的第二次提交：条件是「一周后回看 11 月 11 日前八名」。盯是否还有实质提交，而不是再看一次 star 数。

本报自己也有两条没答上的。一是 A2UI 企业级注册何时从 0.9.1 升到 1.0，二是 Claude Meetings 究竟「已上线」还是「即将到来」——两份材料口径不一致，本报按「部分可用」记，等官方页面统一。承认口径没对齐，比替它挑一个更顺的说法要紧。
