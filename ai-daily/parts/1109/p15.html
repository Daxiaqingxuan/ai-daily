前十条是这一周已经发生的，后面是有明确日期或明确可验证条件的观察清单。本报不写「预计」「有望」。公开报道

  • 计价：Images 2.6 费率与 2.5 相同，但低质量图输出 token 从 196 涨到 823，单张成本约 4.2 倍。
  • 限制：SVG 导出要先出参考图再转矢量，计两次费；GIF 只支持生成端点，编辑端点不能返回 GIF。
  • 价格：GPT-6.1 Terra 每百万 token 输入 1 美元、输出 5 美元，为上一代对半，官方称约 1/10 价格追平 Astra。
  • 准入：Astra 网络安全变体 ExploitGym 48.5%（上一代 32.1%），每百万 20/100 美元，仅对审核客户开放。
  • 框架：ADK 2.14.0 转正 42 个组件，A2A 集成转稳定，脚本执行改为校验路径与参数。
  • 代理：Claude Code 2.1.319 把 MCP 任务转后台，新增「需要批准就直接拒绝」的权限项。
  • 修正：编码代理此前在动作被拒时仍退出 0，脚本会把失败当成功；本版改为退出 1。
  • 治理：四家承诺遵守 robots.txt 的单一训练标记；Anthropic 已实施，微软 2027-02-01 起，Google 目标 2027 年。
  • 开源：Ripple-65B 以 Apache 2.0 放出；753B 科学模型用 MIT 许可但门控；微软放 4B 操作模型。
  • 整合：Meta 收购多 Agent 编排工具 Conductor，云端 11-13 转只读、11-20 关停，本地版维护至 2027 年初。

接下来盯什么（有条件的观察清单）

  • 那行 robots.txt：条件是「2027-02-01 微软生效」。盯是否按期，以及 Google 是否在 2027 前提前落地——它能提前，说明内部的读法已经统一。
  • 按张计价：条件是「官方补一份每张成本表」。盯 OpenAI 会不会在文档里给出正式的单张价目，而不是让所有人拿计算器反算。
  • 框架的 23%：条件是「出现第三方复跑」。盯是否有人给出对比版本、硬件与重复次数；没有这三样，这个数字会一直悬着。
  • 拒绝而不等待：条件是「下一版是否设默认」。盯它会不会成为无人值守场景的默认权限策略——那会改变所有 CI 的行为。
  • Conductor 迁移：条件是「11-20 关停日」。盯是否延期、是否提供导出工具；延期通常意味着迁移量超出预期。

这一期的观察清单里，有四条是「等别人公布一个数字」。这不是偷懒，是因为这几件事的答案只掌握在对方手里——我们能做的只是把「等什么」写清楚。写清条件，比猜结论有用。
