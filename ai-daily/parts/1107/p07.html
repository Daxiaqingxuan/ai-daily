第一种：现在就能下。Cosmos 3 是这周最干脆的一个：四款开放权重、16B 可训练参数、OpenMDW 1.1 许可，商用与非商用都能用，权重和技术报告一起放。Phonon 的 31M 版本也是 Apache 2.0，其余版本 CC BY-NC——同一个项目里两种许可，商用前必须看清自己下的是哪一个。ERNIE 5.5 Flash Base 把 FP8 与 BF16 两版都传了 Hugging Face，但发布材料里没写许可，本报标「未核到」，不替它补。

第二种：给了日期。Inkling 2 Small 先经 Tinker 闭权重提供，明确说安全测试与红队完成后放全量权重、转 Apache 2.0。这是这一周唯一一个把「什么时候给」写清楚的动作。给了日期就可以被追责，没给日期的「近期」不能。

第三种：只说了「近期」。Hy4 是目前能力最强的开源候选，但权重至今只有一句「近期开源」，系统卡片也待发。这不必然是坏事——负责任的开源确实要先做安全评估——但对想部署的人来说，它现在仍然是一个 API 产品，不是一份可下载的权重。把它写进「开源模型」清单时，必须同时写这一句。

本报的读法。判断一个开源动作，只看三行：权重模型训练出来的参数文件。给了权重，你才能自己部署、微调、离线运行；只给 API，能力再强也只能租。下没下、许可写了什么、版本和论文对不对得上。三行都过，再谈分数。「开源」是动作，不是形容词；能下载的才叫开放权重。

锐评 本报评论员 · 针对本版三档成熟度

「近期开源」是这周最软的一句话。它既能让发布稿多一个亮点，又不用承担任何日期责任。衡量一家公司对开源的态度，不看它说得多诚恳，看它敢不敢写月日。Inkling 敢写「下周」，所以它这一项赢的不是参数，是信用。
