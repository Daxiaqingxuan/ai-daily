编辑P005-2

把「未复现 / 未同行评审」做成统一标记

本期正文里这类限定散在括注和句尾，一共十几处，读者很难一眼看出哪些数字是本报核过的、哪些是转述。建议统一成一个行内小标（如「厂商口径」「未复现」「预印本」），并在报尾给一次说明。

为什么
同一页里既有「本报未复现」，也有直接引用的数字，排版上没有区别；换一个编辑写，标记就会漏。

名词速查 · 本期出现的 13 个词正文里带虚线的词点一下就地解释；这张表留作索引
激活参数
MoE 每次推理真正参与计算的那部分参数。Hy4 为 49B（总参 770B），比例约 6.4%；它决定账单，总参数决定上限。
MoE / 混合专家
把模型拆成很多「专家」，每个 token 只叫醒其中几个。能力按总量算，成本按叫醒的数量算。
上下文窗口
一次能送进模型的 token 上限。Hy4 标称 1M，最大输入 960K、输出 64K；标称容量不等于可用容量。
通过率
一次就通过验收的任务占比。比平均分更能预测账单，但换一套任务集就会变，不能跨场景直接比较。
验收清单 / acceptance checklist
调用方提交任务时一起给的那组检查：产物在不在、格式对不对、关键字段有没有。全绿才算干完。
权重 / open weights
模型训练出来的参数文件。给了权重才能自己部署、微调、离线运行；只给 API，能力再强也只能租。
计算机操作 / Computer Use
模型看屏幕、点按钮、敲命令行来完成任务。Hy4 首次支持，并对 Blender、CAD 等专业软件做了专项训练。
端侧推理
模型直接跑在手机、平板、车机这类设备上，不把数据发到云端。代价是模型必须小，能力有上限。
提权 / EoP
elevation of privilege。让普通权限的程序拿到更高权限，是漏洞利用链里最常见的一环。
远程代码执行 / RCE
remote code execution。攻击者能在目标机器上执行任意命令，通常意味着这台机器已经失守。
蒸馏
把大模型的能力搬到小模型上：用大模型的输出当训练目标。搬得好能省算力，搬不好会把老师的偏差一起继承。
增量遗忘 / unlearning
不重训整个模型，只让它忘掉指定的数据或类别。难点是忘掉目标的同时不伤其他能力。
检索增强 / RAG
先从资料库检索相关片段，再让模型基于片段回答。既减少胡编，也减少送进模型的 token。
