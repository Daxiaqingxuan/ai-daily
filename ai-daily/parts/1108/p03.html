能力底座 · 两个方向：向外找漏洞，向内记上下文 第 03 版 / 共 16 版

这一周模型侧有两条线值得记：一条把能力对准代码里的缺陷，一条把能力对准自己的记忆。前者能报出惊人的数字，后者只能报出「更稳了」——但后者才决定智能体能不能连着跑几天。

先说 GPT-6 Cyber。OpenAI 推出的是网络安全专用模型，定位不是通用对话，而是漏洞的发现、验证与修复建议。早期测试面向获批的 Daybreak Red 研究客户开放，最扎眼的数字是在 Linux 内核里找到 948 个漏洞公开报道本报未复现。内核这个量级的代码库，过去做自动化审计只能靠静态分析加人工筛，误报率高到团队宁愿不看；现在换成模型先跑一遍，人工只看被点名的位置。

更值得看的是它怎么被放出来。官方称其在 ExploitGym 专项测试中较上一代提升约 51%厂商口径，同时把模型放进了「准备框架」评估：只对审核批准的安全研究客户开放，配套滥用监测、沙箱隔离、人工复核。换句话说，这是一个有意不追求用户规模的模型——能力越接近「能自己找洞并写出利用」，越不能开放给所有人。远程代码执行remote code execution。攻击者能在目标机器上执行任意命令，通常意味着这台机器已经失守。这类问题一旦被自动化，攻防两侧的门槛会同时下降。

再说记忆。Anthropic 公布了关于智能体记忆的研究，把「记住什么」拆成若干组件，并加入一个叫 dreaming 的机制：在空闲时段整理、压缩、淘汰旧记忆，而不是把所有对话原样堆进上下文。它的意义不在演示，在可靠性——跨会话的智能体最大的敌人不是不会做，是忘了上次做到哪、以及上次为什么改主意。没有这一层，任何「跑一周」的任务都得靠人每天重新交代一遍。

还有一条容易被忽略的底座新闻：百度把 ERNIE 5.5 Flash Base 的预训练终点权重放了出来，280B 总参、14B 激活，基于 33.5T tokens 从零预训练厂商口径。放的是「基座」而不是「成品」——没有做指令微调，等于把后续训练的起点交给社区。这种放法在国内大厂里不常见，对做垂直微调的团队比放一个聊天模型有用得多。

本报的判断是：能力正在从「一个模型什么都能聊」转向「一个模型专门交一类活」，而专用化的代价是必须配套准入与审计。GPT-6 Cyber 的开放策略就是样本：能力越强，越像危险品管理。这不是退步，是这类能力第一次被当成基础设施而不是玩具。

锐评 本报评论员 · 针对本版两条能力线

948 这个数字会被人反复引用，但很少有人问一句：这 948 个里，有几个真能被利用？漏洞数是最容易被放大、也最容易被误读的指标。相比之下，Anthropic 那条「更会记」的新闻没有数字可吹，却更可能决定明年还有没有人愿意把长任务交给智能体。
