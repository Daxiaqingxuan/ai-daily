名词速查 · 本期出现的 13 个词正文里带虚线的词点一下就地解释；这张表留作索引
预印本 / preprint
未经同行评审的论文稿。公开可查，但没有经过期刊审稿流程，数字要按「作者自述」看。
MoE / 混合专家
把模型拆成很多「专家」，每个 token 只叫醒其中几个。能力按总量算，成本按叫醒的数量算。
激活参数
MoE 每次推理真正参与计算的那部分参数。Kimi K3.1 Pro 为 1040 亿（总参 2.8 万亿），它决定账单。
上下文窗口
一次能送进模型的 token 上限。标称容量不等于可用容量，长上下文里的中间段最容易被忽略。
权重 / open weights
训练出来的参数文件。给了权重才能自己部署、微调、离线运行；只给 API，能力再强也只能租。
验收清单 / acceptance checklist
调用方提交任务时一起给的那组检查：产物在不在、格式对不对、关键字段有没有。全绿才算干完。
远程代码执行 / RCE
攻击者能在目标机器上执行任意命令，通常意味着这台机器已经失守。
提权 / EoP
elevation of privilege。让普通权限的程序拿到更高权限，是漏洞利用链里最常见的一环。
端侧推理
模型直接跑在手机、平板、车机上，数据不发到云端。代价是模型必须小，能力有上限。
检索增强 / RAG
先从资料库检索相关片段，再让模型基于片段回答。既减少胡编，也减少送进模型的 token。
蒸馏
把大模型的能力搬到小模型上：用大模型的输出当训练目标。搬得好能省算力，搬不好会把偏差一起继承。
增量遗忘 / unlearning
不重训整个模型，只让它忘掉指定的数据或类别。难点是忘掉目标的同时不伤其他能力。
计算机操作 / Computer Use
模型看屏幕、点按钮、敲命令行来完成任务。它让「自动办事」成立，也让权限边界变得重要。
