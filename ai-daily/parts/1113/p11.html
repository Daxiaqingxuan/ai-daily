消费卡的价签按张算，数据中心的价签按机柜算。今天 AMD 把 MI400 系列的三款卡和一组可比的推理数字一起摆了出来——它是本期第二张价签的上游。厂商口径

先把三款卡的分工说清。MI455X 面向机架级以整个机柜为单位交付与组网的方案，卡、交换与供电一起设计；对客户来说，买的是机柜而不是单卡。推理，配套 Helios 方案；MI450X 同样面向 Helios；MI430X 走科学计算，保留原生双精度，配备 432GB HBM4第四代高带宽显存，用在数据中心加速卡上。容量决定能放多大的模型，带宽决定吐字速度。与最高 23.3TB/s 的显存带宽厂商口径。AMD 同时公布了一项针对 11 款应用、47 种工作负载配置的研究，用来说明哪些科学代码仍必须依赖原生双精度厂商口径。这条比跑分有意思：它在承认「不是所有科学计算都能降精度」。

那组推理数字要连条件一起读。AMD 称 MI455X 驱动的 Helios 在 DeepSeek-R1 的 MLPerf 推理离线配置下达到每 GPU 每秒 21333 token，较英伟达 Vera Rubin 最新公开结果的吞吐高出至多 30%；Helios 在 HBM 带宽与扩展带宽上较 Vera Rubin 也有至多 20% 的提升厂商口径。这是「自家测试对别家公开结果」的比较，不是同一台机器、同一套参数的复跑，本报未独立复现。它足以说明方向——机架级方案的竞争已经从「单卡算力」转到「带宽与扩展」——但不足以说明谁更快。

另一条更贴地的消息：把 API 换成机房。AMD 与 Spectro Cloud 发布企业级本地编程平台 Instinct Coder 355：8 张 MI355X、2 颗 64 核 EPYC 9575F、3TB DDR5-6400 内存与 63.36TB 固态，本地跑 GLM-5.3 推理，称性能逼近前沿模型的 98%，单节点最多服务 85 名开发者、50 人可同时在线编码公开报道。「不出门」是它的卖点：敏感代码与数据不必外送，配套的推理平台默认调用本地算力而不是云 API。这是「本地部署」在组织层面的版本——第 06 版那三笔账，在这一档变成了「一台机器 vs 一年 API 账单」。

本报的读法：机房侧和消费侧抢的是同一批产能。同一片晶圆、同一批 HBM、同一条先进封装线，做成数据中心卡还是消费卡，取决于毛利与订单密度。所以第 05 版那张 4.8 万元的报价，与这一版的机柜报价，是同一个决定的两种结果。看懂这一层，就不会把「显卡贵」当成经销商的问题——它更像是一个分配问题。
