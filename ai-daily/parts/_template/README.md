# 第 16 版模板 · 本报提案

从第 **004** 期起，每期 **16 版**，多出来的一版是「本报提案」（`#p16`）。
这个目录放的是复制用的骨架，不是成品；出报时复制到 `parts/<MMDD>/` 再改。

## 一、复制清单

```
cp parts/_template/00-masthead.html    parts/1107/
cp parts/_template/00-tail.html        parts/1107/
cp parts/_template/00-style-extra.html parts/1107/
cp parts/_template/p16.html            parts/1107/
cp parts/1106/00-style.html            parts/1107/     # 基础样式沿用，不用改
```

`p01`–`p15` 按老规矩写。**注意：第 15 版只写快讯，报尾交给 `00-tail.html`**，别再把 `<footer>` 和右侧目录塞进 `p15`。

> **样式改动写哪里**：`00-style.html` 是从上一期整份复制来的，**没有模板源**——直接改它只会改到当期，
> 下一期又从复制链里带出旧写法。**浮动件与窄屏适配一律写进 `00-style-extra.html`**
> （模板里有这份，拼接顺序在 base 之后，同选择器后写覆盖前写）。
> 004 期修「手机目录按钮遮挡三行摘要」就是这么做的：`extra` 里改 `.mob-btn` 尺寸与收起规则，
> `00-tail.html` 里补滚动收起脚本。

> **模板与当期必须同源**：`00-style-extra.html` 是这些规则的唯一来源。005 期开工时发现模板落后于
> 004 期——缺三行摘要（`.digest`）、术语气泡（`.term`）、手机报头压缩与窄屏目录按钮，照模板复制会
> **静默丢样式**，而自检看不出来。现已把模板对齐到当期完整版；以后改样式，模板与当期一起改。

另外四个文件**不复制，要现写**（004 期起强制，缺了拼不上版）：

```
parts/<MMDD>/00-thread.json    # 本期主线一句话 + 跑偏词 + 阈值
parts/<MMDD>/00-facts.json     # 事实卡：断言 / 数值 / 版面 / 来源 / 时点 / 强度 / 是否复现
parts/<MMDD>/00-blocks.json    # 每版信息来源：官方 / 第三方信息网 / 本报实测 / AI 生成
parts/<MMDD>/00-sources.json   # 信源归属：谁给的 / 给了什么 / 哪一类 / 怎么用
```

最小骨架（照抄再改）：

```json
{ "thread": "一句话主线，3–20 字",
  "offTopicTerms": ["费半", "纳指", "标普", "A股", "沪指", "沪深", "涨停", "收盘", "恒生", "道指"],
  "maxOffTopicPages": 7, "exemptPages": [] }
```

```json
{ "asOf": "YYYY-MM-DD",
  "facts": [{ "id": "F01", "claim": "这条断言", "value": "96.15%", "page": "p01",
              "source": "谁说的", "asOf": "YYYY-MM-DD", "strength": "vendor",
              "reproduced": false }] }
```

```json
{ "maxAiPages": 4,
  "pages": { "p01": { "origin": "official", "note": "谁给的" },
             "p02": { "origin": "ai",       "note": "社论，无外部信源" } } }
```

```json
{ "asOf": "YYYY-MM-DD",
  "policy": "只做事实性引用，未转载全文",
  "sources": [{ "id": "S01", "outlet": "机构名", "item": "被引内容",
                "kind": "官方发布", "usage": "事实性引用，未转载全文" }] }
```

`origin` 只认四档：`official` / `thirdparty` / `measured` / `ai`。标的是**信息主要来自哪**，
不是谁执笔（全部版面都由 AI 执笔）。`kind` 只认四档：官方发布 / 媒体报道 / 预印本 / 公开榜单。

`strength` 只认五档：`vendor` 厂商口径 / `preprint` 预印本 / `media` 公开报道 / `measured` 本报实测 / `estimate` 本报自设。写 `measured` 就必须 `reproduced: true`，反之亦然——这个对账由 A13 做。

## 二、四个文件各管什么

| 文件 | 作用 | 每期要改的地方 |
|---|---|---|
| `00-masthead.html` | 报头 + 16 条导航 + 读报指南 | 日期、星期、期号（搜 `YYYY 年 M 月 D 日` / `第 00N 期`） |
| `00-style-extra.html` | 提案版样式 + 16 项导航在窄屏改 4 列 | 一般不用改 |
| `p16.html` | 四条提案 + 台账表 + 锐评 + 名词速查 | 全部内容（搜 `00N`、`〔`） |
| `00-tail.html` | 报尾 + 右侧目录 + 手机目录面板 + 论据标记图例 | 期号、日期、信息源、编辑说明、更正、往期 |
| `00-thread.json` | 本期主线声明（P005-3） | 每期现写：主线名、跑偏词、阈值 |
| `00-facts.json` | 事实卡（P005-4） | 每期现写：每条外部数字一行，数值必须与正文逐字一致 |
| `00-blocks.json` | 版级来源（P006） | 每期现写：16 版各一行，AI 生成版不得超过 `maxAiPages` |
| `00-sources.json` | 信源归属（P006） | 每期现写：报尾「信息源与归属」表由它渲染，一条一行 |

`assemble_issue.py` 的拼接顺序：`00-style` + `00-style-extra` → 报头 → `p01…p16` → `00-tail` → 事实卡（内嵌 `<script id="ai-daily-facts">`）→ 收尾。

## 三、四条提案的规矩

1. **四个视角各一条，不许多也不许少**：读者 / 编辑 / 创刊人 / AI。编号 `P<期号>-1…4`。
2. **每条必须写清三件事**：要加什么（一句话）、为什么（可核对的理由）、成本（小/中/大 + 改哪几个文件）。
3. **默认不执行**：只有创刊人明确说「采纳 P004-2」才动工；没说就是否决（沉默），不再追问。
4. **台账要结算**：出报前先把上一期的待定项结算（到期转「否决（沉默）」），再登记本期，最后更新 `提案台账.md` 的计数表。
5. **不许原样重提**：被否的提案要复议，编号加 `R`，并写清「上次为什么被否、这次多了什么证据」。

## 四、报错对照表

| 断言 | 报错 | 常见原因 |
|---|---|---|
| A1 | 版数应为 16 | 少复制或多复制了一个 `pNN.html` |
| A2 | 版面 id 不连续 | `pNN.html` 里的 `<section id="pNN">` 没改 |
| A3 | 导航锚点与版面不一致 | 报头导航还是 15 条 / 少了 `<a href="#p16">` |
| A4 | 某处缺「第 00N 期」 | 报头或报尾的期号没替换 |
| A4b | 版数不是「共 16 版」 | 报头/报尾还写着「共 15 版」 |
| A5 | 残留上期期号 | 片段是从上一期整段复制的，`第 003 期` 没清 |
| A6 | 第 NN 版缺锐评块 | 新版没写 `<aside class="razor">` |
| A7 | 第 NN 版缺页码 | 新版没写 `<span class="sec-page">` |
| A8 | 标签未配平 | 手工改 HTML 时漏了闭合标签 |
| A10 | 论据标记用了未登记的词 | 自己发明了「据说」「业内」这类说法，六档词表里没有 |
| A10b | 某版引用了外部数字，但该版没有对应标记 | 事实卡的 `page` 指到这版，正文却没加 `<span class="src-tag">` |
| A10c | 报尾缺论据标记图例 | `00-tail.html` 里的 `.src-legend` 被删了，或图例少了某一档 |
| A11 | 报头没有 data-thread / 与 00-thread.json 不一致 | 复制报头时漏改主线名，或报尾没回显「本期主线：X」 |
| A12 | 跑偏熔断 | 命中 `offTopicTerms` 的版面超过 `maxOffTopicPages`，或头版就命中 |
| A13 | 事实卡校验失败 | 缺字段、id 重复、强度不在五档、`reproduced` 与 `measured` 矛盾、数值在署名的版面里找不到 |
| A14 | 版头缺「来源 · X」/ 登记了不存在的版面 | 片段里手写了错的 `src-org`，或有版没进 `00-blocks.json` |
| A14b | 标了「AI 生成」却挂着外部论据标记 | 两者自相矛盾：要么删标记，要么改 `origin` |
| A14c | 标了官方/第三方/实测，但全版没有论据标记也没有事实卡条目 | 这个「官方」是标签不是出处，补标记或改 `origin` |
| A15 | 「AI 生成」版面超过上限 | 无外部信源的版面太多，`maxAiPages` 默认 4 |
| A15b | 报尾「本期 AI 生成 N 版」与实际不符 | 图例里那句是写死的，改了 `origin` 要同步 |
