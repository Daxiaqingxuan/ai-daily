### Q001 · CSS 是什么意思？

- 提问时间：2026-11-05 22:10
- 出处：读教材时截图的一句「中一段 CSS。绝」，原文在教材第 1 章 —— 「把 144KB 的完整样板 HTML 塞进上下文，只为复用**其中一段 CSS**。绝大部分 token 花在不会变的内容上，真正要写的正文反而成了少数派。」
- 关联章节：第 1 章「上下文工程」、第 2 章「防回归断言」

**一句话定义**

CSS = Cascading Style Sheets，中文叫**层叠样式表**。它不产生内容，只规定内容长什么样。

| 层 | 管什么 | 在你项目里的例子 |
|---|---|---|
| HTML | 页面上**有什么**（结构） | `<section>`、`<h2>`、`<button hidden>`、报纸的 15 个版面 |
| CSS | 这些东西**长什么样**（外观） | 纸白 `#fbf8f0`、墨黑 `#1b1a17`、强调红 `#8c1d18`、宋体分栏、SVG 图宽 1080、360px 不横向滚动 |
| JavaScript | **点了会发生什么**（行为） | 顶栏 `‹ ›` 翻期、`☰ 往期` 开抽屉、读 `issues.js` |

**一行 CSS 怎么读**

```css
h1 { color: #8c1d18; font-size: 22px; }
```

- `h1`：**选择器**，决定「给谁改」——命中所有一级标题
- `{ ... }`：**声明块**，里面一条条 `属性: 值;`
- `color`、`font-size`：**属性**；`#8c1d18`、`22px`：**值**

真实文件在 `ai-daily/site/index.html`：第 15 行 `<style>` 开始是一整段 CSS，16–22 行用 `:root{…}` 定义颜色和字体变量，26 行 `body{background:…;color:…;font-family:…}` 定整页底色字色字体，31 行起 `.topbar{position:fixed;…}` 让顶栏固定。**HTML 里一个字都没写颜色**——把 CSS 全删掉，报纸文字还在，但会变成浏览器默认的黑字白底、没有分栏。

**「层叠」两个字，你已经被咬过一次**

Cascading 的意思是：**同一个元素可能被多条规则同时命中，浏览器按优先级决定听谁的**。

上一轮那个 bug 就是活例子：HTML 写了 `<button hidden>`，但 CSS 里 `.btn{display:inline-flex}` 优先级更高，把浏览器默认的「hidden 就隐藏」盖掉了，本该藏起来的「↻」和「复制链接」全冒了出来。修法是 `site/index.html` 第 24 行：

```css
[hidden]{display:none !important;}   /* 组件自带 display 会盖掉 UA 的 hidden，必须显式兜底 */
```

`!important` 就是把这条规则提到最高优先级。后来我又把它写进了 `examples/validate.py` 的防回归断言（C 组）——以后谁删掉这行，闸门直接拦下。对应教材第 2 章：「故障复盘的产出不该只是一句『以后注意』，应该是一条断言」。

**回到截图那句话：为什么说「抽走 CSS」**

那一段 CSS 指的是报纸的版式规则，几千行、几个月不变。为了复用它而把 144KB 整份样板 HTML 塞进模型上下文（≈48k tokens），其中 99% 是样式和旧正文，真正要写的本期正文反而成了少数派。教材的结论是：把 CSS 抽到 `reference/style.css`、由脚本拼装，**不进提示词**。

好处不只是省 token，更是**模型根本看不到 CSS，也就不可能改坏它**。在提示词里写十遍「不要改样式」是口头约束，把 CSS 抽走是结构约束——后者不会失效。这就是教材第 1 章说的「用结构约束代替口头约束」。

**动手验证（30 秒）**

浏览器打开 `ai-daily/site/index.html` → 按 `F12` → 选中 `body` → 把 `background` 改成任意颜色，页面立刻变色，而报纸文字一个字没动。这就是 HTML 与 CSS 的分工。
